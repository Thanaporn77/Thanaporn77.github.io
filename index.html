About

Promoted from Junior to Senior Developer after one year, I now oversee the development team's work, set project timelines, recommend the technical stack for new projects and am the go-to person when something technical gets stuck.

I work mainly with Laravel, React and Node.js, and have shipped internal management systems, a React Native app with an admin dashboard, a cookie-consent SaaS and 20+ launched projects. I also run developer hiring tests and handle servers, DNS and recovery of hacked or spammed sites.
